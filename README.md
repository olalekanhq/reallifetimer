# Life Timer Pro

I have this cr@zy funny idea 😂
So the idea is I want to create a site, a static page , the function is a stopwatch, and have two buttons down which are start and stop. Pressing the start button will start the timer, pressing stop will now bring up a subscription page of $79.99 weekly, that means they’ll need to upgrade to pro before they can stop the timer. Let’s name it “Life timer”. Use a premium modern design.
